The NumPy Cheat Sheet: What's the Difference?

np.dot vs np.matmul (@)
A @ B • np.matmul(A, B)

Matrix Multiplication (Standard)

Designed specifically for linear algebra. Multiplies the trailing 2D slices and broadcasts leading batch dimensions.

(B, M, K) @ (B, K, N) → (B, M, N)
  • Best for Deep Learning and Transformers
  • Supports NumPy broadcasting across batch axes
np.dot(A, B)

Dot Product / Tensor Contraction

For 1D vectors, it's the inner product. For 2D matrices, it's identical to @. But for 3D+, it contracts the last axis of A with the second-to-last of B across ALL axes!

(B, M, K) dot (B, K, N) → (B, M, B, N)
  • Does NOT broadcast batch dimensions
  • Usually produces larger high-dimensional tensors
A * B • np.multiply(A, B)

Element-wise Multiplication

Multiplies numbers in matching positions. Not matrix multiplication!

[2, 3] * [4, 5] → [8, 15]
  • Requires identical or broadcastable shapes
  • Also known as the Hadamard Product

Under the Hood: It's Just 3 Simple Loops!

Demystifying @

Any 2D matrix multiplication $C = A @ B$ is fundamentally calculated with this simple 3-level nested loop: 

# How A @ B is calculated element-by-element:
for i in range(M):          # 1. Loop through each row of A
    for j in range(N):      # 2. Loop through each column of B
        sum_val = 0
        for k in range(K):  # 3. Multiply matching pairs along K and sum them!
            sum_val += A[i][k] * B[k][j]
        C[i][j] = sum_val

Ready-to-Run NumPy Code

import numpy as np

# Create 2D matrices
A = np.array([[1, 2, 0],
              [3, 1, -1]])   # Shape (2, 3)

B = np.array([[2, -1],
              [1,  3],
              [0,  2]])      # Shape (3, 2)

# Matrix multiplication with @
C = A @ B  # Or np.matmul(A, B)

print("Result Matrix C:\n", C)
print("Shape of C:", C.shape)  # (2, 2)
