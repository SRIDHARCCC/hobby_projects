💡 How Bubble Sort Works

Mechanism: Iterates through the list, comparing adjacent items (A[j], A[j+1]). If they are in the wrong order, it swaps them.

Why "Bubble"? With each complete pass, the largest remaining unsorted element "bubbles up" to its correct final place at the end of the list.

for (let i = 0; i < n - 1; i++) {
  for (let j = 0; j < n - i - 1; j++) {
    if (arr[j] > arr[j + 1]) {
      swap(arr[j], arr[j + 1]);
    }
  }
}

💡 How Selection Sort Works

Mechanism: Divides the array into a sorted part and an unsorted part. Scans the unsorted part to locate the absolute smallest (minimum) element, then swaps it once into its sorted slot.

Key Difference: Unlike Bubble Sort which may swap frequently on every pass, Selection Sort performs at most 1 swap per outer loop pass.

for (let i = 0; i < n - 1; i++) {
  let minIdx = i;
  for (let j = i + 1; j < n; j++) {
    if (arr[j] < arr[minIdx]) minIdx = j;
  }
  if (minIdx !== i) swap(arr[i], arr[minIdx]);
}

⚡ Head-to-Head Comparison: Bubble Sort vs. Selection Sort

Feature Bubble Sort 🧼 Selection Sort 🎯
Core Strategy Repeatedly compares and swaps adjacent elements if out of order. Repeatedly scans for the minimum element and places it at the front.
Best-Case Time O(n) (with early-exit flag if already sorted) O(n²) (always checks every element)
Average & Worst Time O(n²) O(n²)
Number of Swaps High: Up to O(n²) swaps (swaps continuously). Minimal: Exactly O(n) swaps (at most 1 swap per pass).
Stability Stable (preserves relative order of equal items) Unstable (long-range swaps can alter relative order)
Best Used For Educational demonstration; nearly-sorted arrays. When writing to memory/flash storage is expensive (fewer swaps).
