🧱 The 4-Layer TCP/IP Model

How data encapsulates as it descends the network stack:

4. Application Layer (HTTP / DNS / TLS)
Generates HTTP requests, parses HTML/JSON, formats URLs.
3. Transport Layer (TCP / UDP)
Segments data, attaches source/destination ports, ensures in-order delivery and retransmission.
2. Internet Layer (IP / ICMP)
Wraps segments into IP datagrams with source & destination IPs; routed via BGP across AS backbones.
1. Link / Physical Layer (Wi-Fi / 5G / Fiber)
Encodes bits into radio waves (QAM/OFDMA) or optical light pulses across transoceanic undersea cables.
