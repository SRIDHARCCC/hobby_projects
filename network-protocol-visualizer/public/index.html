🧱 The 4-Layer TCP/IP Model
Every web request travels down this stack on your phone and up this stack on the host PC:
4. Application Layer (HTTP / HTTPS / DNS)
Defines format: Headers, URLs, Status Codes, JSON Bodies.
3. Transport Layer (TCP / UDP)
Guarantees reliable ordered packet delivery with 3-Way Handshake (SYN, SYN-ACK, ACK) and flow control.
2. Internet / Network Layer (IP / ICMP)
Encapsulates packets into IP datagrams with source & destination IP addresses; routed via BGP across internet backbones.
1. Link / Physical Layer (Wi-Fi / 5G / Ethernet)
Converts bits into radio frequencies (OFDMA / QAM) or optical pulses across physical fiber optic lines.
🔄 Reverse Tunnel Architecture

How you can reach this local PC from your phone anywhere:

1. Outbound Multiplexing: Residential PCs are protected behind NAT firewalls with private IPs (192.168.x.x). Inbound connections are blocked.

2. Reverse SSH Tunnel: The PC initiates an outbound persistent SSH connection to the cloud tunnel server.

3. Edge TLS Termination: When your phone visits the public HTTPS URL, the cloud proxy accepts the TLS handshake, strips the HTTPS encryption, and forwards the raw HTTP packets through the established SSH pipe directly into Node.js port 3000!
